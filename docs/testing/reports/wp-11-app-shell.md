## 2. 视觉方向

界面采用“数字天文台”方向：

- 三维模型空间使用带蓝色倾向的深海军蓝，不使用常见蓝紫霓虹渐变；
- 课程和二维区域使用暖纸色，形成长文本阅读与模型空间的明确分工；
- 主操作使用稀缺的琥珀色；
- Q/K/V 使用橙、蓝、绿三种稳定语义色，同时保留文字标签；
- 标题使用偏人文的衬线字体栈，正文使用适合中文界面的无衬线字体栈；
- 页面区域通过空间、分隔线和背景组织，不使用层层嵌套卡片；
- 动效只用于视图进入和交互状态变化，并遵循 `prefers-reduced-motion`。

## 3. 响应式策略

| 上下文 | 布局 | 交互 |
| --- | --- | --- |
| 手机，低于 768px | 单视图，课程/2D/3D 标签切换 | 44px 触摸目标、方向键标签导航 |
| 平板，768px～1023px | 课程与 2D 并列，3D 横跨下方 | 同时支持触摸、键盘和指针 |
| 桌面，1024px 及以上 | 左侧课程与 2D，右侧完整模型空间 | 同屏观察、顶部模式切换 |
| 低高度桌面 | 收紧课程间距并隐藏非必要深入区 | 保留主路径与时间轴 |

手机 2D 预览在视口内完整缩放，不依赖页面横向滚动。正式 WP-15 将增加更清晰的局部展开与数值交互。

4. 二维预览只表达结构，不承担真实数值交互；正式计算视图属于 WP-15。
5. 当前移动端视觉验证使用浏览器视口和系统 Chrome，M2/M4 仍需真实 iOS/Android 设备检查。
6. Vite 示例样式和图片文件仍保留在仓库但已不再被入口引用，因此不会进入生产构建；删除文件需按项目规范另行确认。
