# M1｜首个联动版本验收报告

- 验收版本：`8634040` 之后的 WP-19 验收提交（本文所在提交）
- 验收日期：2026-07-24
- 验收范围：Token→Attention→Output 首个垂直切片
- 推送目标：`origin/main`
- 验收结论：通过

## 1. 验收目标

M1 需要证明中文课程、二维计算、三维场景和统一时间轴已经组成一个可运行、可理解、可恢复的产品闭环，而不只是四组彼此独立的演示组件。本次验收覆盖：

1. Token→Attention→Output 八个步骤的完整主路径；
2. 课程、二维、三维和时间轴的共享状态与双向选择；
3. 桌面同屏、360px 移动切换与简化三维；
4. 无 WebGL、Context 丢失、数据错误和本地状态损坏时的安全恢复；
5. 中文内容、键盘语义、减少动态效果和图形文字替代；
6. 单元、组件、端到端、视觉回归和基础性能证据。

参数实验、完整 Transformer 计算链、真实模型下载与浏览器内推理不属于 M1，分别在 M2 和 M3 实施。

## 6. 性能结果

性能用例使用 Vite 本地测试服务器、系统 Chrome、单 worker 执行。步骤反馈在浏览器内部测量“点击按钮到下一帧新步骤标题生效”的时间，避免把 Playwright 进程通信和可访问树轮询算入产品响应。

| 指标 | 预算 | 实测 | 结论 |
| --- | ---: | ---: | --- |
| 桌面首次可交互 | ≤ 3000ms | 646ms | 通过 |
| First Contentful Paint | 记录项 | 740ms | 记录 |
| 三维场景就绪 | ≤ 5000ms | 1604ms | 通过 |
| 步骤可见反馈 | ≤ 100ms | 22.6ms | 通过 |
| 桌面稳态帧率 | ≥ 30 FPS，目标接近 60 | 约 60 FPS | 通过 |
| 移动简化三维帧率 | ≥ 30 FPS | 最低 57.4 FPS | 通过 |
| 移动页面横向溢出 | 不允许 | false | 通过 |
| 最长启动长任务 | 当前自动门槛 < 500ms | 226ms | 通过，列入优化 |
| 未确认模型前的外部请求 | 0 | 0 | 通过 |

以上数值取性能专项连续 3 轮与最终完整 E2E 中观察到的保守值。226ms 的最长任务发生在首次挂载三维依赖期间，高于测试方案中的“尽量低于 50ms”软目标，但没有阻断首屏课程，也没有造成持续低帧率。M2/M4 继续通过更细分包和场景初始化分析降低该值。
