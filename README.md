# Transformer LayerScape｜层境

一个面向中文学习者的 Transformer 交互式解释项目，目标是把二维计算过程、三维模型结构、浏览器内模型推理和分步教学整合为统一体验。

## 技术栈

- React、Vite、TypeScript
- React Three Fiber、Three.js、Drei
- D3、SVG、Canvas
- Zustand、GSAP
- ONNX Runtime Web、Transformers.js
- Vitest、Playwright

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run lint
npm run build
```

项目目前处于需求设计和基础设施搭建阶段。
